# Lessons

- A valid per-record dedup flag does not prevent notification overload when many distinct records cross the same threshold together.
- Founder CC on every P1 operational record is a routing defect even when each individual alert is technically correct.
- Digest cards must preserve actionability with direct record links and a clear owner; a whole-table button alone is not enough.
- This machine can import `C:\tmp\ml-data-sync\app` instead of the repository package during unittest discovery. Force the current repository onto `sys.path` and clear stale `app` modules before loading targeted tests.
