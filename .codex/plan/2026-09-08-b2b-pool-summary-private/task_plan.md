# B2B LinkedIn 入池日报改为负责人私聊

## 目标

把 `LinkedIn线索入池日报` 从外贸 B2B 群发送改为仅私聊外贸负责人；保留外贸助手 App、日报内容、定时频率和数据读取逻辑不变。

## 范围与假设

- 只改 `run_pool_summary()` 的通知路由及必要测试/交接记录。
- 负责人必须从外贸助手 App 自己的收件人映射取得，不能复用其他 App 的 `open_id`。
- 不主动补发测试卡，不手动触发生产日报。
- 当前工作树有其他未提交改动，全部保留且不纳入本次提交。

## 验收标准

1. 正常 `notify=true` 时不再使用 `B2B_GROUP_CHAT_ID`。
2. 日报只发给明确配置的外贸负责人；缺少负责人配置时安全失败，不回退群聊。
3. `frankie_only=true` 仍只发 Frankie，供受保护测试使用。
4. 新增自动测试覆盖负责人私聊、Frankie-only、缺配置不发群。
5. 相关测试、语法检查和差异检查通过。
