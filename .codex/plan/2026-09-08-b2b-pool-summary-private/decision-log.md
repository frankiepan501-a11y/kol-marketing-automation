# 决策记录

## 2026-09-08

### D1：只改路由，不改卡片或工作流频率

- 决定：保留外贸助手 App、卡片内容、18:10 定时和 endpoint 参数。
- 原因：用户只要求取消群发送并改为负责人私聊，扩大修改会增加生产风险。

### D2：禁止缺配置时回退群聊

- 决定：负责人映射缺失或错误时返回明确发送错误，不再用 B2B 群兜底。
- 原因：群兜底会直接违反“只需要私发给负责人”的明确要求。

### D3：汇总日报负责人为吴晓丹

- 决定：默认负责人姓名为吴晓丹，并允许用 `B2B_LINKEDIN_POOL_SUMMARY_OWNER` 显式覆盖；实际接收 ID 继续从 `B2B_LINKEDIN_OWNER_NOTIFY_JSON` 读取。
- 依据：现有 B2B 设计目标是让吴晓丹掌握全局跟进情况，邮件提醒也由吴晓丹承接升级；三位业务员继续各收自己的每日开发卡。

### D4：汇总日报不接受 `chat_id` 或通配收件人

- 决定：只接受吴晓丹精确键下的 `open_id / union_id / email`；任何 `chat_id` 和 `*` 通配都安全失败。
- 原因：仅排除一个已知群 ID 无法证明其他 `chat_id` 是私聊；通配映射也不能证明目标就是负责人。
