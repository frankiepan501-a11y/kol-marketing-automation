# KOL 主表公开落地页与邮箱补全 P0

## 目标

1. 新进入 KOL 主表的记录，自动识别并保存公开官网、Linktree、Beacons 等落地页。
2. 对当前主表做一次全量只读盘点，只把有明确公开证据且不覆盖已有值的结果写回。
3. 邮箱必须来自公开页面，且 Snov.io 精确验证结果为 `valid` 才能写入主表。

## 范围与安全边界

- 飞书 KOL 主表是单一真相源。
- 不猜官网、不猜邮箱，不使用搜索结果摘要作为邮箱证据。
- 不覆盖主表任何已有官网、聚合页或邮箱。
- 同一邮箱已经属于另一 KOL 时不写。
- 每次写入前重新读取该记录，避免并发覆盖。
- 先全量只读扫描，再小批量生产写回；小批量逐条回读 100% 一致后才继续。
- 不发送邮件、不发送飞书卡片、不改 n8n、Zeabur 环境变量或本地 daemon。
- 不降低 KOL 质量筛选标准。
- 报告仅保存汇总和 record_id，不保存完整邮箱或原始 KOL 业务数据。
