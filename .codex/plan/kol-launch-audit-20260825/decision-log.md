# 整改决策记录

## 2026-08-26 · P0 实施口径

1. 后台任务记录必须优先保住当前任务的完整标记和关键业务摘要；历史行可以先淘汰，禁止从当前 JSON 左侧截断。
2. 七层确定性词库是所有活动的基础供给，AI 仅做增量扩展；AI 额度耗尽不能让活动停池。
3. 同一个“关键词 × 国家 × 语言”七天内不重复；超过七天可按来源健康轮转复用，筛选标准不降低。
4. 竞品层只在运营明确选择“新调查/引用历史证据”且证据就绪时启用，不把 NYXI 或其他竞品写成全局默认。

6. 已存在 KOL 只追加本次来源标记，不覆盖其业务字段；精确链接优先，账号名只有唯一匹配时才允许回填。
