## 数据与执行流程

1. n8n 每日只触发一个 NYXI 专用服务请求，必须指定配置行 `recvrM7WDZ0ZV9`，不能调用省略品牌的 `/run`。服务持有单运行锁，防重叠。所有后台步骤返回独立 job_id，定时器只能在最终状态为完成时认定成功，不能把 HTTP 202 当完成。
2. NYXI 的 `search.list` 从上次成功水位往前重叠 48 小时到本次运行时间。新 ID 用 `YouTube + video_id` 去重入竞品帖子库。成功写完帖子才推进 NYXI 水位；失败保持原水位。当天尚无水位时沿用既有安全起点，不做多年历史重扫。
3. 每日仅刷新发布日期在运行时刻前 30 天内的已入库 NYXI 视频的公开播放等数字，再加本轮新发现 ID。更老视频改成每周一分批刷新；每批有明确上限和独立进度，不能让日任务重扫 2,400 多条历史记录。刷新失败不得报告为零更新。
4. 新账号按稳定 YouTube channel ID 去重；排除已核验的两个 NYXI 官方频道 `UCIY4yC2qUCPcM7ws-xTARYg`、`UCbvp-CTcH3Mhtj2UWsSy8sA`。报告的“新 KOL”只能表示非官方候选账号，不能仅凭关键词命中就宣称已签约；误命中或待分析帖要标为候选。日报包含新增帖子数、非官方新账号数、链接、刷新数、失败状态及本次 NYXI search 调用数。无新增时也明确写“采集成功，新增 0”。
5. NYXI 完成后读 Google Cloud 中使用该 `YOUTUBE_API_KEY` 的同一项目当天 `search.list` 配额上限与实际已用量；配额读数必须带项目身份、指标名称、统计时间和时间戳。该读数与采集服务本地调用计数不等价：其他程序也可能消耗同项目额度。若没有同项目、同日期、足够新鲜的真实读数，或权限/接口失败，结果为 `quota_unknown`，8BitDo 不执行。按 YouTube 官方规则，默认搜索独立限额为每日 100 次调用、每页请求计一次，太平洋时间午夜重置；实际数值以项目读数为准。
6. 仅当 `remaining >= estimated_backfill_calls + safety_reserve` 且 NYXI 已完成，允许 8BitDo 从现有 `YouTube历史游标` 运行至多一个 7 天窗口。默认安全余量不少于 20 次搜索；预估需来自已完成窗口的上界，不能只看平均值。搜索每一页前检查预算；预算不足或 Google 返回配额错误时停止，保存查询组/页码的细分断点，下次只续未完成部分；整个窗口完整写入后才将主游标推进到窗口起点。失败、暂停和完成三态必须分开报告。
7. 日报在 NYXI 写入完成后发送一次，并在 8BitDo 结果已知时包含“补采已完成 / 因额度暂停 / 因 NYXI 失败未启动”及下一游标。对同一业务日期与 job_id 的重试须防重复发送。若群发失败，记录明确错误并让任务显示失败，不得静默改用旧机器人。服务层异常不得被 n8n 的 HTTP 成功状态掩盖。

## 组件边界

- 采集器：负责 NYXI 搜索、近 30 天数字刷新、8BitDo 单窗口补采以及帖子/游标写入。输入是现有关键词配置和运行时间；输出是有状态与计数的结果。它不发消息，也不写 KOL 主表。
- 配额闸：只读获取 Google 项目配额快照、计算安全余量、提供每页预算决策。输入含项目身份、当天日期、已用/上限与估算；输出是允许/暂停及原因。读取失败时默认暂停。
- 日报器：使用服务现有 KOL媒体助手飞书凭据，向唯一指定群发送结构化文本；只消费采集结果，不发卡片、不触发回调，也不迁移其它通知。
- n8n：只定时启动、轮询最终状态和暴露失败，不直接决定配额，也不并行启动两个品牌。

## 验收与上线

先用模拟 YouTube/飞书/Google 读数测试：NYXI 成功且余量足、NYXI 失败、配额未知、配额不足、窗口中途耗尽、重复执行、官方频道排除、零新增、旧帖不日刷。再在云端以 preview 核对配置和数量，部署现有服务并回读版本与身份；先向目标群发一条明确标注“测试”的消息，回读 message_id。随后修改现有 n8n 工作流，保留原凭据引用和其它节点配置，回读 active 与每日 cron。首次真实运行只按当天顺序验收，不补发旧日报；核对帖子唯一键、NYXI 水位、8BitDo 游标、群消息和 job 状态。未取得可信 Google 项目配额读数前，可上线 NYXI 每日与日报，但 8BitDo 自动补采必须保持关闭，日报必须明示“配额不可验证，补采暂停”。

回滚：停用现有 n8n 工作流或恢复其完整旧定义；服务回到已验证版本 `d52e2bb`。回滚不得删除帖子或重置历史游标。失败必须留下 job_id、原因和单条可回放线索。
