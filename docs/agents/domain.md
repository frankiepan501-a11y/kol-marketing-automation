# Domain docs

This repository uses a single-context documentation layout.

Before engineering work:

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant ADRs under `docs/adr/` when they exist.
- Use the domain vocabulary defined in those files.
- Surface conflicts with an existing ADR instead of silently overriding it.

If these files do not yet exist, proceed without creating speculative domain documentation.
