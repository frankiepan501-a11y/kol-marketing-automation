# NYXI 单次邮件无通知检查

范围：本地补丁；不部署、不发真实邮件、不修改生产环境。基线 d7030af。

- 既有调用保持默认飞书异常告警和后台校验，不改变其他任务。
- `send_email(..., notify=False)` 保留发送前短正文、草稿原文校验及发送后检查；发送后等待检查完成，不发飞书通知。
- 内容截断、接口错误或暂时查不到邮件必须给调用方明确未通过结果。异常携带已经发送的 message_id；调用方必须停止当前批次，只回查该邮件，不可重新发送。
- 关闭通知仅作用于本次调用，不使用全局开关。
- 模拟覆盖正常、截断、查询异常、发送前拒绝、默认通知、不同并发调用隔离。测试必须禁止真实网络、邮件、飞书。

该参数不是完整NYXI执行器。现有auto_send另有告警和业务写入，尚未接入此参数；不能直接调用auto_send运行全表。候选登记、防重、拒绝/退订、回复承接、真实测试原文和客户端渲染须完成后才能放行。当前检查沿用原长度校验，不把其通过当成产品字段、收件人、客户端渲染或送达全部验证。
