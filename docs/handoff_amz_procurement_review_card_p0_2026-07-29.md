# AMZ EU 采购复核回填卡 P0 交接

## 阶段定位

本节点属于 `采购阶段` 的第一步：采购复核供应商和报价条件。

它不属于：
- ERP 新品录入
- 采购计划确认
- 采购下单
- Listing 上架
- 到货后真实销售验证

当前完整流程边界：

| 大阶段 | 节点 | 产出 | 是否本卡负责 |
|---|---|---|---|
| 选品阶段 | 选品结果确认 | Go / 条件推进 / 暂缓 / 淘汰 | 已完成 |
| 采购阶段 | 采购复核回填 | 同款、MOQ、交期、库存、供应商结论、采购建议；阶梯价和箱规可后补 | 是 |
| 采购阶段 | 最终采购确认 | 确认供应商、首批采购量、是否进入采购计划 | 否，下一节点 |
| 采购阶段 | ERP 新品/采购计划 | SKU/产品资料、供应商、箱规、采购价、采购计划 | 否，最终确认后再触发 |
| Listing 上架阶段 | 上架资料准备 | 标题、五点、图文、合规文案、站点价格 | 否，并行新 session 处理 |
| 运营与监控阶段 | 可售后监控 | 7/14/30 天订单、退货、适配投诉、补货建议 | 否 |

## 卡片目的

采购收到卡片后，只需要做一件事：

按每个产品核对供应商页面、Amazon 主图和套装内容，把供应链复核资料填完整，然后点击 `提交本产品复核`。

每个产品独立提交，不影响同卡其他产品。

## 采购必须回填的信息

| 字段 | 为什么要收集 | 后续用途 |
|---|---|---|
| 同款确认 | 判断供应商是否真的能供 Amazon 样本同款/同套装 | 决定是否继续推进或换供应商 |
| MOQ | 判断建议采购量是否能下单 | 最终采购确认和采购计划 |
| 阶梯价 | 判断压价空间、采购量档位 | 选填；缺失不阻止提交，但最终采购确认/压价时应补 |
| 交期 | 判断是否适合首批快速铺货 | 采购计划和上架节奏 |
| 箱规/尺寸重量 | 影响头程、仓储、ERP 产品资料 | 选填；缺失不阻止提交，但 ERP 新品/物流复算前必须补齐 |
| 供应商结论 | 判断供应商是否可用/备选/不建议 | 最终供应商选择 |
| 采购建议 | 可采购、压价后采购、换供应商、补资料后复核、暂缓采购 | 生成采购确认清单 |
| 是否有现货库存 / 库存数 | 判断能否按建议量快速采购 | 首批采购量和交期判断 |
| 备注 | 型号、颜色、Logo、样品、报价口径等异常 | 给 Frankie/运营最终确认时看 |

P0 先写回候选表已有字段：
- `人审备注`: 追加结构化 `采购复核回填=已提交` 行。
- `采购备注`: 写入采购复核摘要。
- `下一步动作`: 根据采购建议写入后续动作。
- 若 `阶梯价` 或 `箱规/尺寸重量` 为空，系统写入 `后续待补`，但不阻止本产品提交。

暂不新增生产字段，避免字段不存在或单选项不匹配导致采购提交失败。正式化后建议新增字段：

| 建议字段 | 类型建议 |
|---|---|
| 采购复核状态 | 单选：待复核 / 已提交 / 需补资料 / 暂缓 |
| 同款确认 | 单选 |
| MOQ | 文本 |
| 阶梯价 | 长文本 |
| 交期 | 文本 |
| 箱规/尺寸重量 | 长文本 |
| 是否有现货库存 | 单选 |
| 库存数 | 数字或文本 |
| 供应商结论 | 单选 |
| 采购建议 | 单选 |
| 采购复核人 | 文本或人员 |
| 采购复核时间 | 日期时间 |
| 采购复核批次ID | 文本 |
| 采购复核卡片消息ID | 文本 |

## 回调行为

`value.action=amz_proc_review_submit`

提交后：
1. 校验必填项：同款、MOQ、交期、现货、供应商结论、采购建议。
2. 若选择 `有现货`，必须填写库存数。
3. 阶梯价、箱规/尺寸重量允许为空；为空时写入 `后续待补`，带到最终采购确认和 ERP/物流资料节点。
4. 写回当前 `record_id` 的 `人审备注`、`采购备注`、`下一步动作`。
5. PATCH 原卡：该产品显示 `采购复核已提交`，移除该产品表单。
6. 同卡其他产品仍可继续填写。

重复点击：
- 若当前候选行已经有相同复核结果，返回“该产品采购复核已提交，无需重复点击”。
- 若前一次只是收到但写回未完成，会重新补写候选表并更新原卡。
