- 张佳烨个人 open_id 已从客服派卡映射中移除。
- 查不到岗位人员时停止派卡，返回 job_title_no_active_user。

- 任一人操作“发送回复 / 改派 / 升级”后，同一工单的全部卡片副本会同步为相同结果状态。
- 客户回复仍以工单 ID 做三层防重复保护：处理中锁、5 分钟内存锁、工单终态锁；两人接近同时点击时只允许一条回复进入发送流程。
- 其他平台现有人员路由保持不变。
