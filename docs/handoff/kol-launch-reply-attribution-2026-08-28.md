# KOL 集中宣发回复活动归属交接（2026-08-28）

## 业务结论

当系统无法根据原邮件 ID 唯一判断回复属于哪个集中宣发活动时，不再把它从日报排除后静默结束。系统改为给运营一张“活动归属待确认”卡；运营只需从当前活动中选择，确认后回复重新计入对应活动，原有回复审核卡继续使用。

回绝、退订，以及合作结束后的纯道谢可直接收口；“样品已到”“询问发布日期”“提供上稿链接”等仍会改变业务阶段，不能当作无关信息关闭。

## 卡片交接内容

卡片显示：

- KOL、产品、回复意图与原话摘要；
- 候选活动和系统匹配依据；
- 进入方式、活动分池、对象类型；
- 是否规定时间上稿，以及承诺/计划/活动窗口推导出的当前截止时间；
- 一个活动选择控件和一个“确认归属并继续回复流程”按钮。

卡片由聪哥分身3号发送，同一 App 接收回调并 PATCH 原卡为结果态。运营确认后只写活动归属字段，不直接发送 KOL 邮件。
